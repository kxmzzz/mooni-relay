# Mooni Relay — เซิร์ฟเวอร์กลางประกาศ

เอาไว้กระจาย "ประกาศจากแอดมิน" ให้ทุกเครื่องที่เปิดแอป Mooni พร้อมกัน

โฟลเดอร์นี้แยกออกจากตัวแอป — เอาไปวางบนโฮสต์ฟรีแล้วรันตลอด

---

## Deploy บน Render (ฟรี)

1. เอาโฟลเดอร์ `relay/` นี้ขึ้น GitHub (repo แยก หรือ subfolder ก็ได้)
2. เข้า https://render.com → **New → Web Service** → เชื่อม repo
3. ตั้งค่า:
   - **Root Directory:** `relay` (ถ้าอยู่ใน subfolder)
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Environment → Add:** `ADMIN_KEY` = รหัสลับที่คุณตั้งเอง (เช่น `mooni1234`)
4. กด Deploy รอสักครู่ จะได้ URL เช่น `https://mooni-relay.onrender.com`

## Deploy บน Railway (ฟรี)

1. https://railway.app → **New Project → Deploy from GitHub**
2. ชี้ไปโฟลเดอร์ `relay/`
3. Variables → เพิ่ม `ADMIN_KEY`
4. ได้ URL มาแบบเดียวกัน

---

## เอา URL ไปใส่ในแอป

1. เปลี่ยน `https://` เป็น `wss://` — เช่น `wss://mooni-relay.onrender.com`
2. เปิดไฟล์ `core/relay.js` ในตัวแอป ใส่ URL ตรง `DEFAULT_RELAY_URL`
3. `npm run build` ใหม่ แล้วแจกไฟล์ .exe — ทุกเครื่องจะเชื่อม relay อัตโนมัติ

หรือถ้าไม่อยาก build ใหม่ ใส่ URL ได้ที่หน้า **Setting → Announcement Relay** ในแอป

## ส่งประกาศ

เปิด `https://mooni-relay.onrender.com` (URL ตัว https) ในเบราว์เซอร์/มือถือ
ใส่ **รหัสแอดมิน** (ค่า `ADMIN_KEY`) + ข้อความ กดส่ง → ขึ้นทุกเครื่องที่เปิดแอปอยู่

## ล็อกอิน Discord + ยศ "Mooni" (ล็อกไม่ให้คนไม่มียศเปิดแอป)

ให้แอปเปิดได้เฉพาะคนที่อยู่ในเซิร์ฟเวอร์ Discord และมียศ **Mooni**
ถ้ายังตั้งค่าไม่ครบ แอปจะเปิดใช้ได้ตามปกติ (ไม่ล็อก) — ล็อกก็ต่อเมื่อตั้ง env ครบทั้ง 4 ตัว

### 1. Discord Developer Portal — https://discord.com/developers/applications
- **New Application** → ตั้งชื่อ Mooni
- แท็บ **OAuth2** → คัดลอก **Client ID** และ **Client Secret** (กด Reset Secret เพื่อดู)
- **OAuth2 → Redirects → Add Redirect** ใส่:
  `https://mooni-relay.onrender.com/auth/callback`  แล้ว **Save**

### 2. เซิร์ฟเวอร์ Discord ของคุณ
- เปิด **Developer Mode**: User Settings → Advanced → Developer Mode (เปิด)
- **Server Settings → Roles → Create Role** ชื่อ `Mooni` แล้วแจกยศนี้ให้คนที่จะใช้แอป
- คลิกขวายศ Mooni → **Copy Role ID**  = `DISCORD_ROLE_ID`
- คลิกขวาไอคอนเซิร์ฟเวอร์ → **Copy Server ID**  = `DISCORD_GUILD_ID`

### 3. Render → mooni-relay → Environment → ใส่ตัวแปร
| Key | ค่า |
|-----|-----|
| `DISCORD_CLIENT_ID` | จากข้อ 1 |
| `DISCORD_CLIENT_SECRET` | จากข้อ 1 |
| `DISCORD_GUILD_ID` | จากข้อ 2 |
| `DISCORD_ROLE_ID` | จากข้อ 2 |
| `DISCORD_CANDY_ROLE_ID` | ยศ Candy Block — ปลดล็อกการ์ด Candy Block ในหน้า Minecraft (ไม่ตั้ง = ใช้ไอดีเริ่มต้น) |
| `DISCORD_FARMER_ROLE_ID` | ยศ Farmer — ปลดล็อกการ์ดแมพ Farmer ในหน้า Minecraft (ไม่ตั้ง = ใช้ไอดีเริ่มต้น) |
| `DISCORD_DIAMOND_ROLE_ID` | ยศ Diamond — ปลดล็อกการ์ด Mooni Diamond ในหน้า Minecraft (ไม่ตั้ง = ใช้ไอดีเริ่มต้น) |
| `DISCORD_PARKOUR_ROLE_ID` | ยศ Parkour V1 — ปลดล็อกการ์ดแมพพาร์คคอร์ (ไม่ตั้ง = ใช้ไอดีเริ่มต้น `1550867888531968170`) |

| `DISCORD_ROLE2_ID` | ยศในดิสที่สองที่ให้สิทธิ์ถาวร (ค่าเริ่มต้น `1550085695110914089`) |
| `DISCORD_INVITE` | ลิงก์ชวนเข้าเซิร์ฟเวอร์ (เช่น https://discord.gg/xxxx) |

> คนใช้แอปกดปุ่ม "เข้าสู่ระบบด้วย Discord" → ล็อกอินในเบราว์เซอร์ → ถ้ามียศ Mooni ก็เข้าแอปได้
> บัตรผ่านจำไว้ 3 วัน แล้วต้องล็อกอินใหม่ (เช็คยศซ้ำ) — ถ้าถอดยศใครออก ภายใน 3 วันเขาจะหมดสิทธิ์

## 🤖 บอท Uplimit Media (ต้อนรับ + Ticket)

บอทตัวนี้รัน **อยู่ในโปรเซสเดียวกับ relay** — ย้ายมาจากโปรเจกต์ `uplimit-media-bot`
ที่รันบนเครื่อง เพราะโฮสต์ที่เปิด 24 ชั่วโมงมีอยู่ที่นี่แล้ว

- เขียน env `UPLIMIT_*` ตามตารางด้านบน → เปิดใช้เองทันที · ไม่ตั้ง = ปิด (relay ทำงานปกติ)
- ทำงานเหมือนเดิม: ต้อนรับสมาชิกใหม่ · คำสั่ง `/ticketpanel` · ปุ่มเปิด/ปิดตั๋ว
- ข้อความ/ปุ่มของแผง Ticket อยู่ที่ `uplimit/data/messages.json` (แก้ในโปรเจกต์นี้แล้ว push)
- ดูสถานะได้ที่ `GET /health` ช่อง `uplimit` หรือกด 🩺 ตรวจระบบในหน้า `/panel`

> ⚠️ **อย่าเปิดบอทตัวเก่าในเครื่องพร้อมกัน** — สองโปรเซสที่ต่อกับแอปเดียวกันจะทำให้
> ข้อความต้อนรับ/การกดปุ่มทำงานซ้ำ · ถ้าต้องเปิดแดชบอร์ดแก้ข้อความ ให้ใช้
> `npm run dashboard` ในโปรเจกต์เก่า (โหมดนั้นไม่ต่อ Discord)

## หมายเหตุ

- **Render ฟรีจะหลับหลังไม่มีคนใช้ ~15 นาที** ครั้งแรกที่ส่งอาจช้า ~30 วิ (ปลุกเซิร์ฟเวอร์)
  ถ้าอยากให้ไม่หลับ ใช้ตัวปิงฟรี (เช่น UptimeRobot) ยิง `GET /health` ทุก 5 นาที
- รหัสแอดมินกันคนอื่นแอบส่ง — ห้ามบอกใคร และควรตั้งให้เดายาก
- เซิร์ฟเวอร์นี้ไม่เก็บข้อมูลอะไร แค่ส่งต่อประกาศ

## 🩺 ถ้าแผงจัดการสมาชิกขึ้น "0 สมาชิก" หรือกดยศ / เปิด Ticket ไม่ได้

เปิด **`/panel` → ปุ่ม 🩺 ตรวจระบบ** ระบบจะไล่เช็คให้ทีละอย่าง (ค่าตั้งต้น · คลังข้อมูล · บอทล็อกอิน · เซิร์ฟเวอร์ · สิทธิ์และลำดับยศ · รายชื่อสมาชิก · บอท Muffin · ห้องและหมวดหมู่ของ Ticket · Public key) แล้วบอกสาเหตุจริงพร้อมวิธีแก้

| อาการที่เจอ | สาเหตุที่พบบ่อย | วิธีแก้ |
|---|---|---|
| `401: Unauthorized` | โทเคนบอทถูกยกเลิก / พิมพ์ผิด | Discord Developer Portal → Bot → **Reset Token** → อัปเดต `DISCORD_BOT_TOKEN` (และ `MUFFIN_BOT_TOKEN`) ใน Render → Redeploy |
| `403` + `50001` | บอทไม่ได้อยู่เซิร์ฟเวอร์ หรือไม่ได้เปิด Server Members Intent | เชิญบอทเข้าเซิร์ฟเวอร์ + เปิด **Server Members Intent** ที่หน้า Bot |
| `403` + `50013` | บอทขาดสิทธิ์ หรือยศบอทอยู่ต่ำกว่ายศที่จะให้ | ให้สิทธิ์ Manage Roles / Manage Channels และลากยศบอทให้สูงกว่ายศที่ต้องจัดการ |
| `404` + `10004` | `DISCORD_GUILD_ID` ไม่ถูกต้อง | คลิกขวาชื่อเซิร์ฟเวอร์ → Copy Server ID แล้วตั้งค่าใหม่ |
| `404` + `10003` / `10011` | ไอดีห้อง / หมวดหมู่ / ยศ ในหน้าตั้งค่าไม่ถูก | คัดลอกไอดีใหม่จาก Discord แล้วกรอก |
| บอทไม่เห็นห้อง Ticket | บอท Muffin ไม่มีสิทธิ์ในห้อง/หมวดหมู่นั้น | ให้สิทธิ์บอทในห้องและหมวดหมู่ที่จะสร้าง Ticket |

ระบบจะ **ตัดช่องว่าง ขึ้นบรรทัดใหม่ อัญประกาศ และคำว่า `Bot ` ที่ติดมากับค่าที่ก๊อปวาง** ให้อัตโนมัติ (ค่าไอดีจะเหลือเฉพาะตัวเลข) · หน้าแผงจะโชว์จำนวนข้อมูลในคลัง (สิทธิ์ใช้แอป / วันหมดอายุยศ) เพื่อยืนยันว่าข้อมูลยังอยู่ · และ log บน Render จะมีบรรทัด `[discord] ...` ทุก 10 นาที บอกว่าบอทล็อกอินได้ไหม

## ⏳ ถ้าดิสคอร์ดตอบว่า "blocked ... exceeding global rate limits"

บางช่วง IP ขาออกของ Render (เป็น IP ร่วมกับผู้เช่ารายอื่น) จะถูกดิสคอร์ด **แบนชั่วคราว** ทำให้ทุกอย่างที่ต้องคุยกับดิสคอร์ดล้มพร้อมกัน: หน้าแผงขึ้น 0 สมาชิก · ให้ยศไม่ได้ · เปิด Ticket ไม่ได้ · ล็อกอินใหม่ไม่ได้ (คนที่ล็อกอินอยู่แล้วยังใช้แอปได้ตามปกติ 3 วัน)

**เช็คได้เอง:** เปิด `https://mooni-relay.onrender.com/health` ดูช่อง `discord` → `"ok": true` = ปกติ · `"status": 429` = ยังโดนบล็อกอยู่ (รอสักครู่แล้วรีเฟรช) · หรือกด 🩺 ตรวจระบบในหน้าแผง

**แยกให้ออกว่าเป็นที่โทเคนหรือที่ IP:** รัน `node tools/check-bot.js` บนเครื่องตัวเอง (ดูวิธีใช้ด้านบนของไฟล์) — ถ้าที่บ้าน ✅ แต่บน Render ❌ = เป็นที่ IP ของโฮสต์ ไม่ใช่โทเคน

**ลดโอกาสโดนซ้ำ:** relay แคชผลเช็คยศ 45 วิ (และรายชื่อสมาชิก 20 วิ) จึงยิงดิสคอร์ดน้อยลงหลายเท่า และกดให้/ถอดยศในหน้าแผงจะล้างแคชให้เห็นผลทันที · ดูจำนวนคำขอที่ยิงจริงได้ที่ `dcCalls` ใน `/health`

**ถ้ารอแล้วยังไม่หลุด (หรืออยากกันไว้ก่อน):** ยิงคำขอไปดิสคอร์ดผ่าน **Cloudflare Worker** แทนได้ โดยไม่ต้องย้ายโฮสต์ — โค้ดพร้อมวิธีตั้งอยู่ใน [`tools/discord-proxy-worker.js`](tools/discord-proxy-worker.js) (ฟรี ไม่ต้องใช้บัตรเครดิต) แล้วตั้งใน Render:

```
DISCORD_API_BASE = https://<ชื่อ-worker>.workers.dev/<รหัสที่ตั้งใน Worker>
```

จากนั้น Redeploy แล้วดู `/health` → `customApiBase` ต้องเป็น `true` และ `discord.status` ต้องไม่ใช่ 429 อีก
